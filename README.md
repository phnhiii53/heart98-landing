# heart98 landing page

Static landing page for heart98.

## Deploy to Vercel

This folder is ready to deploy as a static site.

Upload or import the `heart98-landing` folder to Vercel. No build command is required.

Recommended Vercel settings:

- Framework preset: Other
- Build command: leave empty
- Output directory: leave empty
- Install command: leave empty

Main file:

- `index.html`

Assets:

- `assets/images`
- `assets/fonts`

Project brief:

- `PROJECT_BRIEF.md`
